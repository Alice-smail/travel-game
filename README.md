# 定向旅游小游戏 - 环球港→佘山

一个基于微信扫码进入的H5定向旅游小游戏，融合实名认证、出行条件识别、游戏化互动机制，通过轻量化H5技术实现沉浸式、社交化、数据驱动的旅游体验。

## 📋 项目简介

本项目以「普陀区环球港 → 上海佘山」为核心旅游路线，通过三个阶段的设计（实名认证 → 车票认证 → 游戏化互动），构建一个融合旅游服务、社交互动与数据分析能力的定向旅游小游戏。

## ✨ 核心功能

### 阶段一：实名认证
- ✅ 年龄段选择（儿童/青少年/成人/老年）
- ✅ 性别选择
- ✅ 所在城市输入
- ✅ 游玩偏好标签多选（亲子/休闲/户外/摄影/徒步/探索）
- ✅ 构建初始用户画像

### 阶段二：车票认证
- ✅ 车次/时间段选择（上午/下午/晚上）
- ✅ 年龄分类（儿童/成人/老年）
- ✅ 目的地分类（佘山主景区/周边景点）
- ✅ 出行目的选择（旅游/亲子/休闲/徒步探索）
- ✅ 自动用户分类与分组

### 阶段三：3D游戏地图

#### 🗺️ 路线系统
- **三条可选路线**：
  - 路线一：经典路线（红色）- 环球港 → 休息站A → 观景台 → 佘山
  - 路线二：舒适路线（青色）- 环球港 → 休息站A → 卫生间A → 休息站B → 佘山
  - 路线三：快速路线（黄色）- 环球港 → 卫生间B → 佘山
- 路线可视化展示
- 智能路线规划

#### 🎯 景点系统
- **景点类型**：
  - 🏛️ **旅游景点**（红色塔状图标）- 环球港、佘山国家森林公园、观景台
  - 🏖️ **休息站**（蓝色带顶棚结构）- 提供饮水、休息服务
  - 🚻 **卫生间**（白色建筑结构）- 公共卫生间服务
- 精美的3D图标设计
- 点击查看景点详情
- 浮动动画效果

#### 👥 社交互动系统
- **互动模式**：开启/关闭互动功能
- **角色移动**：点击地面移动角色
- **附近用户检测**：自动检测8个单位内的其他用户
- **互动提示**：靠近用户时显示"💬 点击互动"提示
- **互动类型**：
  - 协作任务（50%概率）
  - 信息共享（50%概率）
  - 简单打招呼

#### 🎮 任务系统
- **探索任务**：根据选择的路线自动生成任务列表
- **协作任务**：
  - 协作拍照：与用户一起在景点拍照打卡
  - 信息交换：交换路线信息，解锁隐藏景点
  - 共同探索：一起探索新区域，发现彩蛋奖励
- **任务完成机制**：
  - 点击对应POI点完成探索任务
  - 到达景点完成拍照任务
  - 再次互动完成信息交换任务
  - 探索多个地点完成探索任务
- **实时任务追踪**：任务列表实时更新，完成显示绿色

#### 💬 实时消息系统
- 显示同路线在线用户数量
- 模拟实时消息流
- 快捷消息发送
- 系统消息通知

## 🚀 快速开始

### 运行方式

1. **直接打开**：
  ```
用 VS Code 打开，安装「Live Server」插件；
右键点击文件 → 「Open with Live Server」；
此时会在本地启动一个服务（如 http://127.0.0.1:5500），可以在浏览器测试功能：
点击「完成实名认证」→ 模拟认证；
选择车票类型 → 提示路线规划；
点击 3D 场景中的绿色球体（佘山）→ 显示景点 + 厕所信息；
打开控制台 → 能看到实时更新的在线用户数。
  ```

### 使用流程

1. **实名认证**
   - 填写年龄段、性别、所在城市
   - 选择游玩偏好标签（可多选）
   - 点击"下一步：车票认证"

2. **车票认证**
   - 选择车次/时间段
   - 选择年龄分类、目的地分类、出行目的
   - 点击"进入游戏地图"

3. **游戏体验**
   - 选择路线（点击"查看路线"按钮）
   - 点击地面移动角色
   - 点击景点查看详情并完成任务
   - 开启互动模式，靠近其他用户进行互动
   - 接受并完成协作任务

## 🎮 操作指南

### 基本操作
- **移动角色**：点击地图上的任意位置，角色会平滑移动到该位置
- **查看景点**：点击景点图标查看详细信息
- **完成任务**：点击对应的景点或与其他用户互动完成任务
- **切换路线**：点击"查看路线"按钮选择不同路线

### 互动操作
1. **开启互动模式**：点击底部"👥 互动模式"按钮
2. **移动靠近用户**：点击地面移动到其他用户附近（8个单位内）
3. **查看互动提示**：靠近后用户上方会显示"💬 点击互动"
4. **触发互动**：点击其他用户触发互动
5. **接受任务**：如果是协作任务，点击"接受任务"添加到任务列表
6. **完成任务**：根据任务类型完成相应操作

### 任务完成方式

#### 普通探索任务
- 点击对应的POI点（如休息站、观景台、佘山等）
- 系统自动检测并完成任务

#### 协作任务
- **协作拍照**：接受任务后，点击任意景点（红色塔状图标）即可完成
- **信息交换**：接受任务后，再次点击触发任务的用户即可完成
- **共同探索**：接受任务后，需要点击2个不同的POI点才能完成（会显示进度）

## 🛠️ 技术栈

- **前端框架**：原生 HTML5 + JavaScript + CSS3
- **3D引擎**：Three.js (r128)
- **3D渲染**：WebGL
- **实时交互**：模拟 WebSocket（本地模拟）
- **动画**：CSS3 动画 + Three.js 动画循环

## 🔧 自定义配置

### 修改景点数据
在 `index.html` 中找到 `pois` 数组，可以修改：
```javascript
const pois = [
    { name: '景点名称', position: [x, y, z], type: 'attraction|rest|toilet', description: '描述' }
];
```

### 修改路线
在 `routes` 数组中修改路线配置：
```javascript
const routes = [
    {
        name: '路线名称',
        pois: [0, 2, 4, 1], // POI索引数组
        color: 0xff6b6b // 路线颜色
    }
];
```

### 调整互动距离
修改 `checkNearbyUsers` 函数中的 `interactionDistance` 变量：
```javascript
const interactionDistance = 8; // 互动距离阈值
```
